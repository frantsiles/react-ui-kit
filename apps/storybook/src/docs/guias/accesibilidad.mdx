# Accesibilidad

Objetivo: **WCAG 2.2 nivel AA**. Cada historia pasa un chequeo automático de axe en claro, oscuro y alto contraste, en el CI y en vivo en el panel *Accessibility*; cada componente tiene además tests de teclado y de nombres accesibles.

Lo automático detecta cerca de un tercio de los problemas. El resto se cubre con las reglas de diseño de esta página y con pruebas manuales.

## Qué garantiza el kit

| Criterio WCAG | Cómo lo cumple el kit |
| --- | --- |
| 1.1.1 Contenido no textual | Íconos decorativos ocultos (`aria-hidden`); los significativos piden `label` |
| 1.3.1 Información y relaciones | `<label for>` real; ayuda y error conectados con `aria-describedby` |
| 1.4.1 Uso del color | Errores con ícono + texto; tags de estado con ícono |
| 1.4.3 / 1.4.11 Contraste | Tokens verificados en los tres temas (ver *Colores y tokens*) |
| 1.4.10 Reflow | Controles fluidos; funcionan a 320 px de ancho y con zoom al 200 % |
| 2.1.1 Teclado | Todo es operable con teclado (ver *Foco y teclado*) |
| 2.4.7 / 2.4.11 Foco visible | Anillo de foco con `outline`, visible también en colores forzados |
| 2.5.8 Tamaño del objetivo | Botones internos de 24 × 24 px como mínimo |
| 3.3.1 / 3.3.3 Identificación y sugerencia de errores | `ErrorMessage` + `aria-invalid`; la guía pide mensajes que digan cómo corregir |
| 3.3.2 Etiquetas o instrucciones | `Field` exige `label`; el placeholder nunca la reemplaza |
| 4.1.2 Nombre, función, valor | Elementos nativos; `aria-pressed` en mostrar contraseña |

## Qué le toca a tu app

- **Textos claros.** Etiquetas que dicen qué pedir y errores que dicen cómo corregir.
- **Gestión del foco** después de acciones (enviar, borrar, abrir diálogos).
- **Idioma.** `<html lang="es">`. Los textos por defecto del kit están en español y se cambian por props (`toggleLabel`, `clearLabel`, `removeLabel`, `optionalText`).
- **Contraste propio.** Si personalizas tokens, revisa *Colores y tokens*.

## Cómo probar

1. **Panel Accessibility** de Storybook en cada historia.
2. **Solo teclado:** recorre la historia con `Tab`, actívala con `Enter` y `Espacio`.
3. **Zoom al 200 %** y el viewport móvil de la barra superior.
4. **Lector de pantalla:** NVDA (Windows), VoiceOver (macOS / iOS) o TalkBack (Android).
5. **Tema alto contraste** y **RTL** desde la barra superior.
