# Label

La etiqueta de un control de formulario. Dentro de un [`Field`](?path=/docs/inputs-field--docs) se asocia sola; suelta, usa `htmlFor`.

<Primary />
<Controls />

## Reglas

- **Siempre visible.** Si el espacio no alcanza, usa `Field` con `hideLabel`, pero solo cuando el contexto visual es obvio (un buscador con lupa).
- **Clic en la etiqueta enfoca el control.** Agranda el área de clic, algo especialmente útil en móvil.
- **Requerido u opcional, no ambos.** Si la mayoría de los campos son obligatorios, marca los opcionales (`optional`). Si la mayoría son opcionales, marca los requeridos (`required`).
- El asterisco de `required` es solo visual. Lo que anuncia "requerido" es el atributo `required` del control, que `Field` pone solo.
